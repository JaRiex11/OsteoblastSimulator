# Видение проекта

**Проект:** desktop-приложение для вероятностного моделирования колонизации клеток в трёхмерной пористой решётке имплантата (рабочее название — Bone Lattice Simulator).

**Документ:** подготовка к разработке (инициация проекта).

---

## 1. Введение. Основное назначение проекта

Информационная система предназначена для **in silico** исследования процессов заселения пористой решётчатой структуры клетками различных типов (остеобласты, мезенхимальные стромальные клетки, фибробласты) при фиксированных правилах миграции и пролиферации.

Система формирует дискретную трёхмерную модель поровой сети, выполняет пошаговую agent-based симуляцию, вычисляет метрики заполнения (занятость пор, T50/T90) и сохраняет результаты в форматах, пригодных для анализа и включения в отчётность.

Назначение — **сравнительный анализ влияния топологии связности решётки** на динамику колонизации, а не замена полноценных биомеханических или клинических расчётов.

---

## 2. Позиционирование информационной системы. Формулировка проблемы

**Проблема:** при проектировании пористых имплантатов требуется оценить, как структура пор и каналов между ними влияет на скорость и характер распространения клеточных популяций. Полноценное моделирование с учётом механорегуляции, ангиогенеза и дифференциации клеток требует значительных вычислительных ресурсов и специализированных пакетов, что затрудняет быстрые итерации на этапе выбора топологии решётки.

**Автоматизируемый процесс:** построение параметризованной 3D-поровой сети → задание начальных условий и параметров клеток → серия дискретных шагов симуляции → сбор статистики и визуализация → экспорт артефактов для документирования эксперимента.

**Границы системы:** приложение не проектирует геометрию имплантата из CAD/КТ, не ведёт учётные записи пользователей, не интегрируется с СУБД. Хранение — файлы JSON/CSV/VTK/PNG в локальной папке `output/`.

## 3. Заинтересованные лица

| Роль | Описание | Интерес |
|------|----------|---------|
| **Исследователь / студент** | Проводит курсовые или учебно-исследовательские эксперименты | Сравнение пресетов решётки, воспроизводимость (`seed`), материалы для отчёта |
| **Инженер-конструктор (предварительный этап)** | Оценивает варианты пористой структуры до тяжёлого CAE | Качественная оценка связности и скорости заполнения |
| **Преподаватель / научный руководитель** | Оценивает корректность постановки и реализации | Соответствие требованиям, прослеживаемость результатов |
| **Разработчик (сопровождение)** | Поддерживает и расширяет код | Модульная архитектура, тесты, CLI |

Прямые **пользователи** системы — лица, запускающие симуляцию через GUI или CLI на рабочей станции с установленным Python или собранным исполняемым файлом.

## 4. Задачи системы

### Задачи высокого уровня

1. Генерировать трёхмерные кубические поровые сети с заданной топологией связей (регулярная, разрежённая, полная 26-связность).
2. Моделировать поведение клеточных агентов: миграция, пролиферация, ограничение «одна клетка — одна пора», разрешение конфликтов (contact inhibition).
3. Предоставлять средства визуализации и количественной оценки (графики, 3D, T50/T90).
4. Обеспечивать экспорт и воспроизводимость экспериментов.

### Задачи пользователей

| Задача пользователя | Поддержка системой |
|---------------------|-------------------|
| Сравнить две топологии при одинаковых параметрах клеток | Пресеты `regular_6` / `random` / `full_26`, фиксированный `seed` |
| Задать состав и начальное размещение клеток | Поле «Состав», режимы `center` / `face` / `random` |
| Наблюдать динамику заполнения | Вкладки «Графики», «3D Viewer», анимация |
| Сохранить результаты для отчёта | Экспорт CSV, JSON, VTK, PNG |
| Выполнить серию прогонов без GUI | CLI (`python run.py --bone --cli`) |
| Оценить параметры в физических единицах | Режим Biological Physics (`dt`, `total_time_hours`) |

---

## 5. Перспективы информационной системы

1. **Импорт геометрии** имплантата (STL/сегментация КТ) с построением поровой сети вне кубического шаблона.
2. **Пакетный режим** в GUI: очередь экспериментов по сетке параметров с сводной таблицей метрик.
3. **Расширение биологической модели:** дифференциация МСК, поля концентраций, ангиогенез (опционально).
4. **Параметризация связности** по целевому среднему числу соседей ⟨k⟩, а не только по доле удаления каналов.
5. **Сравнение с эталонными данными** in vitro (калибровка вероятностей).

## 6. Преимущества относительно сходных решений

| Аспект | Типичный подход (CAE / универсальные ABM-платформы) | Данная система |
|--------|---------------------------------------------------|----------------|
| Предметная область | Общий инструмент, требует самостоятельной сборки модели | Специализация на поровой решётке имплантата и трёх типах клеток |
| Порог входа | Высокий (скрипты, настройка сетки) | GUI с предустановленными пресетами и подсказками |
| 3D-топология | Задаётся вручную или внешними пакетами | Генерация через OpenPNM, пресеты связности |
| Воспроизводимость | Зависит от сценария пользователя | Фиксированный `seed`, экспорт JSON с параметрами |
| Артефакты отчёта | Разрозненные | Единый экспорт прогона (CSV, JSON, VTK, PNG) |
| Развёртывание | Сервер / лицензии | Desktop, Python или standalone `.exe` |

Система **не конкурирует** с COMSOL, Abaqus или NetLogo по широте; она закрывает узкий класс задач — **быстрое сравнение lattice-топологий** при упрощённой клеточной динамике.
