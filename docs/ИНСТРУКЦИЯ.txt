СТРУКТУРА ПРОЕКТА
-----------------
  run.py                 — запуск (GUI или CLI)
  osteoblast_sim/        — исходный код
    graph/               — построение решёток
    simulation/          — движок симуляции
    visualization/       — графики и анимация
    app/                 — CLI и GUI
  docs/                  — документация
  output/                — результаты экспериментов (CSV, PNG)
  scripts/build_exe.bat  — сборка .exe
  dist/                  — готовый OsteoblastSimulator.exe (после сборки)


1. УСТАНОВКА (для разработки)
------------------------------
    pip install -r requirements.txt


2. ЗАПУСК БЕЗ КОНСОЛИ
---------------------

  A) Готовый exe (рекомендуется):
     1) Запустите scripts\build_exe.bat (один раз, нужен Python).
     2) Откройте dist\OsteoblastSimulator.exe двойным щелчком.
     3) Результаты кнопки «Запустить и сохранить» — в папке output\ рядом с .exe.

  B) Из исходников:
     python run.py
     (откроется то же окно GUI)


3. КОМАНДНАЯ СТРОКА (для серии экспериментов)
----------------------------------------------
    python run.py --help

    python run.py --graph-type grid_2d --size 15 --p-migrate 0.5 --p-prolif 0.25 ^
        --time-steps 200 --save-csv exp.csv --no-show

    python run.py --graph-type random --nodes 100 --degree 6 --seed 42


4. ПАРАМЕТРЫ
------------
  --graph-type     grid_2d | random | small_world
  --size           сторона сетки (grid_2d)
  --nodes          число пор
  --degree         связность решётки
  --p-migrate      вероятность миграции
  --p-prolif       вероятность пролиферации
  --time-steps     шаги симуляции
  --initial-cells  center | random | 0,5,10
  --color-mode     occupancy | colonization | local_density
  --animate        анимация
  --save-csv       CSV в output/ (или полный путь)
  --save-plot      PNG кривой занятости
  --save-graph     PNG схемы графа


5. GUI
------
  Запустить              — симуляция + графики на экране
  Запустить и сохранить  — + CSV и PNG в output/
  Открыть папку output   — каталог с результатами

  Параметры окна сохраняются автоматически в gui_settings.json
  (рядом с .exe или run.py): при запуске, после «Запустить» и при закрытии окна.
