2. НАЗНАЧЕНИЕ И ПРОИСХОЖДЕНИЕ ИМЁН
---------------------------------

2.1. Корень проекта
-------------------

run.py
  Зачем: главный файл запуска. Без аргументов или из .exe — открывается GUI;
         с аргументами (--graph-type, --p-migrate, …) — режим командной строки.
  Имя: стандартное «запусти программу отсюда».

requirements.txt / requirements-build.txt
  Зачем: список библиотек для pip install.
  Имя: общепринятое в Python-проектах.

gui_settings.json
  Зачем: последние введённые в окне параметры (тип графа, P_migrate, seed…).
  Откуда: создаётся модулем app/settings.py при запуске и закрытии GUI.
  Расположение: рядом с run.py или рядом с .exe в dist/.

OsteoblastSimulator.spec, build/, dist/
  Зачем: сборка автономного exe через PyInstaller.
  dist/ — distribution, «дистрибутив» для пользователя без Python.


2.2. Пакет osteoblast_sim
-------------------------

osteoblast = остеобласт (костеобразующая клетка);
_sim = simulation (симуляция).

__init__.py, __main__.py
  Соглашения Python: папка — импортируемый пакет; -m osteoblast_sim — альтернативный запуск.

paths.py
  Зачем: единое определение «корня» (папка с run.py или с exe) и каталога output/.
  Важно для exe: пути не привязаны к месту установки исходников.


2.3. graph/ — структура имплантата как граф
-------------------------------------------

Вершина = пора; ребро = канал между соседними порами.

builder.py (ранее graph_generator.py в корне)
  Функции:
    - grid_2d           — регулярная 2D-сетка (все ортогональные связи)
    - grid_2d_random    — те же узлы на сетке, случайное подмножество связей
                          (планарный bond-percolation; опция --diagonals)
    - random            — случайный граф Эрдёша–Реньи (нерегулярная пористость)
    - small_world       — граф «маленького мира» (Watts–Strogatz)
  Имя builder: «строитель» графа по параметрам эксперимента.


2.4. simulation/ — биологическая динамика
-----------------------------------------

engine.py (ранее simulation.py / simulation_engine.py)
  Содержит:
    - SimulationConfig     — P_migrate, P_prolif, число шагов, seed
    - OsteoblastSimulation — пошаговая модель клеток
    - SimulationResult     — история занятости, T50/T90, счётчики событий
    - export_results_csv   — выгрузка для Excel / Origin
  Модель: на каждом шаге для каждой клетки независимо миграция и пролиферация
  (Khayyeri et al., lattice approach).
  Имя engine: «движок» расчёта, отделён от интерфейса.


2.5. visualization/ — наглядность для научной работы
----------------------------------------------------

charts.py (ранее visualizer.py)
  - draw_graph           — схема пор (зелёный/серый и др.)
  - plot_occupancy_curve — S-кривая заполнения
  - show_dashboard       — граф + кривая + текст метрик
  - animate_simulation   — покадровая анимация
  - save_graph_png       — экспорт рисунка в PNG
  Имя charts: графики (matplotlib), не путать с «графом» graph/.


2.6. app/ — как пользователь запускает эксперимент
--------------------------------------------------

experiment.py
  Связывает: параметры → build_graph → OsteoblastSimulation → результат.
  Используется и CLI, и GUI (без дублирования логики).

cli.py
  Разбор аргументов командной строки (--help), сохранение в output/.

gui.py
  Окно tkinter: поля параметров, кнопки «Запустить», «Сохранить», лог отчёта.

settings.py
  Чтение/запись gui_settings.json, проверка корректности значений.


3. СЛУЖЕБНЫЕ И ГЕНЕРИРУЕМЫЕ ПАПКИ
---------------------------------

output/
  CSV и PNG после экспериментов (из исходников: python run.py).

dist/output/
  То же при работе через OsteoblastSimulator.exe.

build/
  Кэш PyInstaller. Не редактировать. Можно удалить — пересоздастся при сборке.

.git/
  История версий Git. Не относится к логике симулятора.

---------------------------------------------

  Постановка задачи          → описание в README/введении + graph/, simulation/
