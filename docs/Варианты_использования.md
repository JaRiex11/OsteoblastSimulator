# Варианты использования информационной системы

**Система:** Bone Lattice Simulator (desktop, `bone_lattice_sim`).

**Акторы:** *Исследователь* — пользователь, выполняющий эксперимент; *Система* — приложение.

---

## Развёрнутые варианты использования

### UC-01. Сравнение скорости колонизации для двух топологий решётки

| Поле | Описание |
|------|----------|
| **Идентификатор** | UC-01 |
| **Название** | Сравнить колонизацию при `regular_6` и `random` |
| **Актор** | Исследователь |
| **Предусловия** | Приложение установлено; параметры по умолчанию загружены из `bone_gui_settings.json` (при наличии). |
| **Постусловия** | Получены два прогона с метриками T50/T90; при экспорте — две папки `output/run_*`. |

**Основной сценарий:**

| Шаг | Действие актора | Ответ системы |
|-----|-----------------|---------------|
| 1 | Открывает приложение (`python run.py --bone`). | Отображается главное окно, вкладка «Конфигурация». |
| 2 | Задаёт размер решётки N=12, топологию `regular_6`, состав `osteoblast:5`, режим `center`, seed=42, число шагов 200. | Сохраняет значения в полях формы. |
| 3 | Нажимает «Запустить симуляцию». | Проверяет поле «Состав»; при ошибке — сообщение. При успехе — запускает `SimulationWorker` в фоне. |
| 4 | Переходит на вкладку «Графики». | Обновляет кривые занятости и числа клеток по шагам. |
| 5 | Дожидается завершения прогона. | В журнале выводит сводку (занятость, T50, T90); вкладка «Экспорт» активирует кнопку экспорта. |
| 6 | Записывает T50/T90 первого прогона. | — |
| 7 | Меняет только топологию на `random`, долю удаления throats 0,3; seed и остальные параметры не меняет. | Обновляет поля. |
| 8 | Повторяет шаги 3–5. | Формирует второй результат с теми же метриками. |
| 9 | Сравнивает кривые и T50/T90 вручную или по экспортированным CSV. | — |

**Расширения:**

- **3а.** Некорректный «Состав» — система показывает предупреждение, прогон не начинается.
- **5а.** Пользователь нажимает «Стоп» — система завершает текущий шаг и останавливает симуляцию с частичным результатом.

**Задействованные классы (план):** `MainWindow`, `ConfigTab`, `SimulationWorker`, `ExperimentService`, `LatticeEngine`, `Simulation`, `ChartsTab`, `ExportTab`.

### UC-02. Смешанный старт клеток с грани имплантата и просмотр в 3D

| Поле | Описание |
|------|----------|
| **Идентификатор** | UC-02 |
| **Название** | Моделировать конкуренцию типов клеток при старте с грани |
| **Актор** | Исследователь |
| **Предусловия** | Приложение запущено. |
| **Постусловия** | Выполнен прогон; доступна анимация заполнения; зафиксированы числа клеток по типам. |

**Основной сценарий:**

| Шаг | Действие актора | Ответ системы |
|-----|-----------------|---------------|
| 1 | На вкладке «Конфигурация» задаёт `initial_mode=face`, состав `osteoblast:5,fibroblast:5`. | Принимает параметры. |
| 2 | Нажимает «Предпросмотр» на вкладке «3D Viewer» (опционально). | Строит решётку без симуляции; отображает стартовые клетки на грани min-Z. |
| 3 | Запускает симуляцию. | Выполняет UC-01, шаги 3–4; параллельно может записывать кадры для анимации. |
| 4 | Открывает «3D Viewer», включает «Живое 3D» (при необходимости). | Обновляет сцену с интервалом «3D каждые K шагов», если вкладка активна. |
| 5 | После завершения нажимает «▶ Анимация». | Проигрывает записанные кадры; останавливается на последнем кадре. |
| 6 | Анализирует распределение типов по графику «Число клеток по типам». | — |

**Расширения:**

- **4а.** «Живое 3D» отключено — симуляция выполняется; финальный кадр показывается по завершении.

**Задействованные классы:** `ViewerTab`, `LatticeViewer3D`, `VisualSnapshot`, `Simulation`, `ChartsTab`, `build_initial_from_settings`.

### UC-03. Экспорт полного прогона для отчёта

| Поле | Описание |
|------|----------|
| **Идентификатор** | UC-03 |
| **Название** | Сохранить артефакты эксперимента |
| **Актор** | Исследователь |
| **Предусловия** | Завершён хотя бы один прогон симуляции. |
| **Постусловия** | В каталоге `output/run_YYYYMMDD_HHMMSS/` созданы `timeseries.csv`, `run.json`, `lattice.vtk`, `charts.png`. |

**Основной сценарий:**

| Шаг | Действие актора | Ответ системы |
|-----|-----------------|---------------|
| 1 | Переходит на вкладку «Экспорт». | Отображает статус «Готово к экспорту: … клеток, занятость …%». |
| 2 | Нажимает «Экспорт всего (CSV + JSON + VTK + PNG)». | Вызывает `export_full_run`; записывает файлы в `output/run_*`. |
| 3 | Читает список путей в поле журнала экспорта. | Выводит имена файлов и папку. |
| 4 | Передаёт PNG и CSV в пояснительную записку или ParaView (VTK). | — |

**Расширения:**

- **2а.** Ошибка записи на диск — диалог с текстом исключения.

**Задействованные классы:** `ExportTab`, `SimulationRun`, `ExportService`, `SimulationResult`.

|-----|-----------------|---------------|
| 1 | Формирует команду с параметрами (`--preset`, `--size`, `--steps`, `--seed`, `--export-dir`). | — |

## Краткие варианты использования

### UC-05. Предпросмотр решётки без симуляции

**Актор:** Исследователь. **Цель:** проверить размер сетки и начальное размещение клеток.  
**Сценарий:** задаёт параметры → «Предпросмотр» на 3D Viewer → система строит `LatticeGraph` и отображает стартовые клетки.  
**Классы:** `LatticeEngine`, `ViewerTab`, `VisualSnapshot`.

---

### UC-06. Симуляция в режиме Biological Physics

**Актор:** Исследователь. **Цель:** получить вероятности и шаг `dt` из физических констант.  
**Сценарий:** включает чекбокс физического режима → система пересчитывает P_mig/P_prol и dt → запускает прогон → в CSV появляется `total_time_hours`.  
**Классы:** `BiophysicsCalibration`, `SimulationConfig`, `ConfigTab`.

---

### UC-07. Остановка длительного прогона

**Актор:** Исследователь. **Цель:** прервать расчёт при большом N.  
**Сценарий:** «Стоп» → worker устанавливает флаг отмены → симуляция завершается на текущем шаге → частичный результат доступен для экспорта.  
**Классы:** `SimulationWorker`, `Simulation.run(cancel_check)`.

---

### UC-08. Сохранение параметров между сеансами

**Актор:** Исследователь. **Цель:** восстановить последние настройки.  
**Сценарий:** при закрытии/запуске система читает и записывает `bone_gui_settings.json` (размер, preset, вероятности, seed).  
**Классы:** `SettingsRepository`, `ConfigTab`.
